# 🏰 Riddle-Realm-3D

**Riddle-Realm-3D** is a thrilling riddle-based escape adventure game where players must solve challenging riddles to navigate through a mysterious building and escape! 🌟

## 🎮 Game Summary

In **Riddle-Realm-3D**, the player finds themselves trapped in a strange building. The only way to escape is by solving riddles in each room. Choose the right answer, and you'll progress further into the realm. Choose incorrectly, and it’s game over! 🧩 The game features multiple rooms, with each riddle presenting new challenges as the difficulty increases with each step forward.

## 🎯 Goal

The objective of the game is to successfully escape the building by solving all the riddles. Players must decipher the clues given in each room and choose the correct door to move forward. Careful thinking and logic are required to avoid wrong choices and ensure a successful escape! 🏃‍♂️🏃‍♀️

## ✨ Key Features

1. **Riddle-Based Gameplay**: Each room provides a unique riddle that helps players choose the correct door to advance.
2. **Multiple Pathways**: Various paths lead to different outcomes—safe rooms guide you forward, while wrong choices end the game.
3. **Progressive Difficulty**: As players progress, riddles become increasingly complex, requiring more thought and deduction.
4. **Atmospheric Setting**: The game takes place in a suspenseful and immersive environment, designed to keep players on the edge of their seat.

## 🚀 Getting Started

### 1. Clone the repository

 ```bash
 git clone https://github.com/your-username/Riddle-Realm-3D.git
 ```

### 2. Open in Unity
 - Open Unity Hub.
 - Select the Riddle-Realm-3D project from the directory where you cloned the repository.
 - Click Open to load the project.

### 3. Play the Game
 Once the project is loaded, hit the Play button in Unity to start exploring the Riddle-Realm-3D!
